# BoiPara Nexus

BoiPara Nexus is a smart academic heritage platform inspired by College Street, Kolkata.

## Features

- Interactive knowledge zone map
- Book discovery and search
- Student Adda (peer-to-peer exchange)
- Heritage stories section
- Authentication system
- Responsive UI

## Tech Stack

- React
- Vite
- JavaScript
- CSS
- Firebase

## Vision

To preserve academic heritage while helping students discover books and connect through a modern digital experience.

## Status

Currently under active development for hackathon submission.
